# 金属丝独立观察页验证

2026-11-05。金属丝模型 v1.0.0；合集 v1.5.0。

已同步“OPU数据分析”的金属丝讨论，核对SMA模型说明及验证文件。几何为33/30 µm同轴圆柱，1 mm去皮段、10.2 mm照片估算涂层间隔。自由跨距、牵引轮和放线筒是新工况示意，不修改原CAD或保留蓝色底板。

34项Node测试通过（11项金属丝与23项原观察版测试），包括原XZ、FES/RF和光路版本全部文件与49820a6的字节哈希一致。原完整性检查与14项光路数值检查通过。

金属丝浏览器检查通过：初始中心、运行/暂停、输入锁定、1.5 µm台阶、材料引起的两路变化、独立ADC时钟、采样相位漏检、CSV元数据、横摆回光、无效信号、无效参数以及360 px布局。HTTP页面和file离线打开均通过，无页面错误或失败资源；桌面/窄屏截图已人工查看。首页、原FES/RF Bump交互回归通过。

几何模型检查中的典型结果：20 mm/s、1 mm标记、9 Hz采样，在首个标记附近，相位0时得到0个完整裸丝点，相位0.5时得到1个。它证明采样可能漏标记，不是实机检出率测定。

本版保留固定焦点，不新增自动Z校正、不保证0/1输出。涂层35%／裸丝75%、默认4 µm尺度、暗电平以及圆瞳倾角损失均是声明的代理假设；未实测丝材电压、真实涂层干涉或BRDF。0%反射率特例按暗电平且无效处理，避免将无反射误判成合焦。

数值与显示共用同一材料坐标、同一采样函数。边界采用轴向高斯累计积分、横向五点积分。参考曲线工作点使用同一个积分读出，不另造一条不一致曲线。各ADC时间单独求值，CSV区分模型与ADC记录。500 Hz细线仅为显示采样，不用于声称捕获任意高速过渡。
