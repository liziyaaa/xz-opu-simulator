# 金属丝连续进给观察仿真 v1.0.0

单独入口 wire/v1.0.0，保留现有演示不变。固定 OPU，从右卷筒放线、左侧牵引。开始时照在线材顶部横向中心，初始未去皮段的 FES 位于选定中心支路。固定焦点观察，不擅自加自动跟焦或可靠0/1判决。

来源：OPU数据分析 2026-11-05 金属丝讨论；SMA 模型说明/verification。外径33 µm、金属30 µm，同轴顶部差1.5 µm，去皮段1 mm、间隔10.2 mm（照片估算），沿轴向周期进给。初始位于10.2 mm涂层段中点。自由跨距放卷为新场景，不保留样品底板；卷筒、牵引轮是示意尺寸。

预测层次：几何精确使用给定半径；FES/RF 使用既有35%/95%参考的线性材料函数与假设4 µm尺度。裸丝/涂层默认反射率是可调假设，未实测。先按单一不透明反射面，无涂层多层干涉、偏振、散斑或真实BRDF。透明涂层工况不声称准确。

有限光斑以可复现高斯数值积分混合边界；纵向/横向运动同一时间/材料坐标。可选角度回光损失使用等半径角域圆瞳重叠代理，明确近似。电压围绕用户可调暗电平缩放；暗电平默认是rho=0参考函数外推，非实测。越出经验响应域时留空，不外插伪有效高度。轴向运动均匀段不虚构振荡；可控横摆/竖振/反射率差分别展示。

独立ADC采样点：默认FES50 Hz、RF9 Hz，单独时钟、RF可调采样相位；保留连续模型与采样点，不伪造MHz HF载波。显示1 mm标记停留时间、每标记RF样本数。记录带参数/出处/有效性导出CSV，暂停仍可看曲线，参数变化重置基准记录，最多60秒/有限记录。

界面：宏观牵引与放卷动画、等比例微观纵剖/横截面、当前几何和信号、FES/RF参考工作点与过程曲线；开始/暂停/单步/重新置中、送线速度、手动材料位置、振动扰动/对照预设。页面离线相对路径可开。发布为新路径，不改旧仿真文件，版本审计记录来源哈希。

验证：初始中心/固定焦点；1.5 µm跳变；周期和进给方向；均匀段不振荡；采样相位漏检；横摆/失焦不等于0；材料相同/可反转；边界混合；越域保留空值；暂停/速率/参数重置；360px布局/资源/导出；旧版本哈希保留。
