OPU 光路 / 四象限 · v2.0.0

模型日期：2026-10-13 · 公开分享适配：2026-10-15。此版与本地最终版使用相同的计算源码，只增加项目导航并移除未使用的外部辅助脚本。

怎样观察

  1. 默认含 0.6 mm PC。将样品 Z 调到 −1 / +1 µm，观察光斑方向和两组对角象限的能量变化；同向移动物镜应给出相反离焦响应。
  2. 直接拖动 PC、物镜和样品；按住 Shift 拖动可微调。样品 Z 正值表示远离物镜，物镜 Z 正值表示靠近样品。
  3. 默认大口径理想平行 PC 轴向移动时，总分层相位不变，不应人为生成信号变化。将 PC 直径缩小到 1 mm，再靠近物镜，可观察有限口径截光。
  4. 移除 PC 后原位置严重失焦。点击“样品移至理论最亮面”只寻找该参考模型的最亮面，不强制将 FES 归零。残余球差可能使最亮面与 FES 零点不同。
  5. 改变像散间距、探测面位置、片厚/折射率、样品倾角或微台阶后，等待 17 点 S 曲线重新求解完成。光斑放大只改变显示，不改变积分区域。

哪些进入了计算

高斯激光源 → 光栅主阶 → 准直镜 → 分光/折转元件 → 等效物镜 → 分层 PC / 样品 → 反射回瞳 → 像散镜 → 探测面复振幅 → 四象限有效区域积分。四路信号来自传播强度积分，不是预存的椭圆动画。

输出为归一化 FES：(a+c−b−d)/(a+b+c+d)，不是实机 mV。只计算 650 nm DVD 主通道，不同时计算三种波长或 E/F/G/H 跟踪副光束。

参考参数与假设

DVD 参考参数：波长 650 nm、NA 0.60、物镜焦距 3.05 mm、工作距离参考 1.67 mm。参考覆盖层厚 600 µm、折射率 1.58。物镜用参考基材预补偿的等效瞳相位表示，没有虚构原厂非球面处方。

截图没有提供内部尺寸。源到准直镜 6 mm、准直镜焦距 6 mm、准直镜到物镜折叠路程 18 mm、像散平均焦距 8 mm / 焦面间距 80 µm、探测面宽 160 µm / 分割死区 1 µm、分光及镀膜效率均为明确的参考假设。完整参数可在演示内展开。

模型边界

  • 标量高斯/角谱与薄相位面参考模型，不是完整矢量电磁仿真，也不是 SF-HD65 的原厂尺寸或光学处方复刻。
  • 分光按标量效率处理；没有完整偏振 Jones 模型。PC 鬼像、多重反射干涉、真实表面散射、机械噪声与电子增益没有全部建模。
  • 微台阶/倾斜面是局部薄相位面近似。边缘混合回光不能直接解释成一个唯一的真实高度。
  • 强失焦可能超出 256 / 512 网格的数值解析范围。系统会提示无效，不能把虚假平衡当作对焦。
  • 源码核对与数值收敛性检查证明计算一致性，不等于与实际设备的电压、灵敏度或精度吻合。
