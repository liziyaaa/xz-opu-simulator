2．FES与RF从哪里来

复用2026-11-04硅片35%、镜片95%八次配对扫描的代表响应，分别对两路电压进行仿射插值。它们只提供响应形态，不是金属丝材料实测。涂层35%、裸丝75%为可调初始假设，裸丝不必一定更亮。35%～95%之外属于未验证外推。

参考没有同步Z记录，中心支路宽度默认4 µm是空间尺度假设；真实丝上的斜率、焦点和摆幅需要分别扫描两种表面后替换。初始记录基准是初始点的模拟电压，FES的中心电压不必为0 mV。焦面始终固定，材料变化不会偷偷重设零点或跟焦。

RF是当前ADC1测到的低频回光电压通道代理，不合成MHz载波或预设数字方波。FES/RF源记录独立相对时标的配对只近似对齐；本页合成时间轴不意味着原实测已同步。

3．光斑、弯曲和倾角

DVD参数按SF-HD65参考：λ=650 nm，NA=0.60。Airy第一暗环直径 d=1.22λ/NA=1.322 µm。数值积分用σ=d/4的高斯主瓣代理，不是精确Airy光场：轴向用高斯累计积分混合两种表面，横向用五点带权积分。忽略相干叠加，因此不能预测边界衍射、干涉、表面粗糙度或散斑。

局部高度 z=√(r²−y²)+z扰动，横向倾角 θ=asin(y/r)。半径15 µm时横偏5 µm对应顶部下沉约0.858 µm、中心镜面反射偏转约38.94°。倾角对回光的影响有物理依据，但本页具体损失函数是近似：以α=asin(NA)为圆瞳角半径，圆心分离2|θ|，用两个等圆的重叠比例g；这不是高NA完整光线追迹或BRDF。

电压 V=Vdark+g(Vreference−Vdark)。默认Vdark取ρ=0参考曲线在中心的外推，并非暗电平实测，可手动修改。FES和RF的电气偏置不会因丢光自动归零。涂层暂按不透明单反射面；若实物透明、多层、氧化或有纹理，必须另测/另建模。

4．采样、有效性与记录

连续信号按解析材料位置计算；细线500 Hz显示，ADC0/ADC1分别按50 Hz/9 Hz取点，RF相位可调。没有模拟ADC时间窗、真实滤波器、通信延迟和量化。高速下细线本身也可能错过窄边界，但各ADC时刻均独立求值。噪声参数使用两个确定性高频正弦分量作扰动，不代表实测噪声频谱。

采样数近似 N=fRF×1 mm/v。1 mm标记在20 mm/s时仅停留50 ms，9 Hz采样可能整个漏掉；相位可复现实验。失焦、跑出线材、低回光或边界混合单独标记无效，不能强行判0。有效性依赖用户假设的中心线性宽度和代理回光门限g>0.1，这个门限不是实机验收标准。超出参考响应域的数值留空。

CSV分别标记model_500Hz、ADC0_FES、ADC1_RF，包含参数、几何、基准、暗电平、材料、混合占比、回光系数、离焦和无效原因。记录最多60秒，参数改变会重新开始，刷新不会持久保存；切工况前先导出。暂停时可改参数重建记录；已导出的文件不受影响。
