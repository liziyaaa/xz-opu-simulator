尺寸与光学依据

依据 SF-HD65 S03，印刷页码 3–4。焦斑为理想圆孔径 Airy 中央斑第一暗环直径：d = 1.22 λ / NA；按 µm 尺寸显示，不人为加大。

这是按手册参数计算的理想焦斑，不是本装置实测光斑。未模拟入瞳填充、像差、倾斜面、材料或离焦扩斑；光学模式不会替代实测 FES 标定。

样品为原五个参考模型的名义尺寸，部分基片为局部截取；并非已购买实物的测量认证。微观与装配窗口角度同步，横纵空间比例一致；换视野不清空数据。

默认 DVD 仅为演示初始选择，实际激光模式需按接线确认。切换 DVD/CD 会重置记录，并更新模拟边缘判定所用的焦斑范围。装配 4.78 mm 间隙不是经验证的工作距离。

计算流程：X 按所设速度到点，Z 保持，连续记录 FES；用已确认支路上的历史趋势确定优先回正方向。到点后直接测量、回中或固定 X 搜索，候选验证、停稳平均后才合成高度。搜索不重置 FES₀/Z₀。边缘点留空继续，后续单一表面重新找焦；搜索失败、软限位或记录上限仍暂停。

仿真边界：光斑、回波、支路、稳定过程为理想示意；X 匀速不保证采到完整峰谷。方向趋势仅为优先线索，矛盾、噪声大或采样不足时不猜方向，按限程双向搜索验证。10/50 nm 为读数量化，不是准确度。实测 DAC F 曲线不参与微米高度换算。

空间与安全：允许暂时失焦不等于允许碰撞。边缘留空不是插值补高度；实际设备仍需软硬限位、碰撞保护和安全搜索路径。取消“边缘点留空继续”可恢复逐点严格暂停模式。
