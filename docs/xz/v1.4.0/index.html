尺寸与光学依据

依据 SF-HD65 S03，印刷页码 3–4。焦斑为理想圆孔径 Airy 中央斑第一暗环直径：d = 1.22 λ / NA；按 µm 尺寸显示，不人为加大。

这是按手册参数计算的理想焦斑，不是本装置实测光斑。未模拟入瞳填充、像差、倾斜面或离焦扩斑；材料电压响应采用两锚点线性假设；光学模式不会替代实测 FES 标定。

样品为原五个参考模型的名义尺寸，部分基片为局部截取；并非已购买实物的测量认证。微观与装配窗口角度同步，横纵空间比例一致；换视野不清空数据。

默认 DVD 仅为演示初始选择，实际激光模式需按接线确认。仅 DVD 几何模式与此次实测参考配合；切换模式会重置未开始的行，并更新模拟边缘判定所用的焦斑范围。装配 4.78 mm 间隙不是经验证的工作距离。

逐点策略　X 到位后固定，电机沿 Z 采集 FES 和光栅读数。扣除共同偏置，在主峰与主谷之间拟合中心段，取过零光栅位置。近程未包含完整 S 曲线时，在所设范围与软限位内扩大扫程。

按需策略　首点必扫。只有整段 X 移动和到位信号均稳定时才保持 Z，使用最近一次拟合的局部斜率处理微小残差。FES 越带、RF 变化、信号缺失、X 采样过稀或到达复扫间隔时重新扫 Z。

模型边界　不同材料可能改变过零位置，光斑跨边缘由几何近似判定。FES 和 RF 同时相近的异常仍可能漏检。电机匀速、读数量化和响应尺度均为仿真假设；现场需用同高异材件和已知台阶验证。
