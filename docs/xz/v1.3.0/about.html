XZ FES / RF Bump 观察版 v1.3.0

2026-11-04。先观察信号，不新增 RF 联合找焦策略。本版不连接硬件，不证明实机 Bump 可以完整测量。

操作顺序

  1. 默认样品为连续公共硅底板的 2×3 分区阵列，共2094个凸点，高50 µm。使用俯视图、Y数值或滑块模拟手动放置。
  2. 设置X起终点、步长和材料反射率。硅基底初值35%，凸点初值95%只是模拟值，不是锡实测。
  3. 开始或单步后锁定当前行参数；暂停也不解锁。观察FES与RF的共同位置标记、两路过程记录和原FES找焦动作。
  4. 失败时保留信号与原因，不输出伪有效高度。可按原流程重试或显式跳过无效点；这不是新增的硬件运动策略。
  5. “结束并保存当前行”会保存记录，解除Y锁定。再换Y扫描；历史轮廓按各行自身相对基准叠加，不代表统一绝对高度面扫。
  6. 可导出当前行、原始过程或历史行。历史数据只在当前浏览器会话内保存，关闭/刷新前请导出。最多20行且内存容量有限，超过时会提示，不静默删除。

材料函数

w=(ρ−0.35)/0.60；分别计算 FES=FES硅+w(FES镜−FES硅)、RF=RF硅+w(RF镜−RF硅)。两个通道都保留实测偏置，不计算FES/RF。35%～95%为指定锚点之间的插值，其外为未验证线性外推。

数据和空间尺度

参考为2026-11-04镜片、硅片各8次扫描。按原相对时间配对，统一中心与峰序；RF间隔超过0.5秒不插值。两通道不是经验证的共同硬件时标，不解释亚秒同步。u是共同扫描相位，不是Z位置。

原记录无同步Z位移，默认将中心20%～80%电压支路映射到4 µm只是演示假设。参考标定默认固定在35%材料，每行开始冻结，跨到凸点不会自动重新拟合，因而材料变化造成的偏差/失败会保留下来。
